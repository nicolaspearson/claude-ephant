# Markdown

A `.md` file, read in an editor, on a forge or in a viewer that renders
GitHub-flavoured Markdown. Read at a desk, often more than once, so it can carry
the whole core with its evidence.

## Markup

Everything GitHub-flavoured Markdown renders:

- A `#` title, then `##` sections whose headings say what each answers
- Tables, where several items share the same fields
- Links as `[text](url)`, the URL a public one the reader can open
- Code, field names and values in backticks

## Length

No cap. The core in full, each finding with its evidence and its `as of` date.

## Render

1. Write the render to `<scratch>/render.md` from the core, in its order,
   shortening or reshaping and never adding a claim, keeping every item the
   core holds, each at least a line
2. Count its characters for the brief: `wc -m < <scratch>/render.md`
